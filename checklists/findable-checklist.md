# Findable Checklist

Focusing on the "Findable" principle of FAIR.

## Identifiers (F1)
- [ ] A persistent identifier (PID) has been assigned to the data.
- [ ] A persistent identifier (PID) has been assigned to the metadata.
- [ ] The PID is globally unique (e.g., DOI, Handle).
- [ ] The PID is resolvable (e.g., https://doi.org/...).

## Metadata (F2)
- [ ] Metadata includes basic descriptive information (Title, Author, Date).
- [ ] Metadata includes domain-specific attributes.
- [ ] Keywords are included to aid searchability.

## Linking (F3)
- [ ] The metadata record contains the PID of the data it describes.
- [ ] The data file (if possible) contains the PID of its metadata.

## Indexing (F4)
- [ ] The dataset is deposited in a recognized repository.
- [ ] The repository is indexed by major search engines (e.g., Google Dataset Search).
