# Interoperable Checklist

Focusing on the "Interoperable" principle of FAIR.

## Language (I1)
- [ ] Metadata is provided in a machine-readable format (JSON-LD, XML, RDF).
- [ ] Data is provided in a non-proprietary format (CSV, TXT) where possible.

## Vocabularies (I2)
- [ ] Controlled vocabularies are used for key attributes (e.g., species, tissue type).
- [ ] The vocabularies used are themselves FAIR (have PIDs, are documented).
- [ ] References to the vocabularies are included in the metadata.

## References (I3)
- [ ] Links to related datasets are included.
- [ ] Links to associated publications are included.
- [ ] Links are "qualified" (the relationship type is specified).
