# Reusable Checklist

Focusing on the "Reusable" principle of FAIR.

## Rich Description (R1)
- [ ] Variable names are clearly defined.
- [ ] Units of measurement are specified.
- [ ] Missing value codes are defined.
- [ ] Experimental conditions are described in detail.

## Licensing (R1.1)
- [ ] A standard license is applied (e.g., CC-BY, MIT).
- [ ] The license is embedded in the metadata.
- [ ] The license is included in the data files (e.g., in the header).

## Provenance (R1.2)
- [ ] The source of the data is clearly stated.
- [ ] Processing steps (data cleaning, normalization) are documented.
- [ ] Software versions used for processing are listed.
- [ ] All contributors are acknowledged.

## Community Standards (R1.3)
- [ ] The dataset follows the standard format for its domain (e.g., FASTQ for genomics).
- [ ] The metadata follows the standard schema for its domain (e.g., MIAME).
