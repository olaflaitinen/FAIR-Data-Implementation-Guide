# Accessible Checklist

Focusing on the "Accessible" principle of FAIR.

## Protocol (A1)
- [ ] Data is accessible via a standardized protocol (HTTP, FTP).
- [ ] Metadata is accessible via a standardized protocol.

## Openness (A1.1)
- [ ] The protocol is free to implement (no proprietary software required).
- [ ] The protocol is open source.

## Authentication (A1.2)
- [ ] If data is open, direct download is available.
- [ ] If data is restricted, the login page is accessible.
- [ ] The process for requesting access is clearly documented.
- [ ] Contact information for the data steward is provided.

## Persistence (A2)
- [ ] The repository has a data retention policy.
- [ ] The repository guarantees metadata persistence even if data is deleted.
