# FAIR Assessment Checklist

Use this checklist to evaluate the "FAIRness" of your dataset.

## Findable
- [ ] **F1**: Does the dataset have a globally unique and persistent identifier (e.g., DOI)?
- [ ] **F2**: Is the dataset described with rich metadata?
- [ ] **F3**: Does the metadata explicitly include the identifier of the data?
- [ ] **F4**: Is the dataset registered or indexed in a searchable resource (e.g., Zenodo, PubMed)?

## Accessible
- [ ] **A1**: Is the data retrievable by its identifier using a standardized protocol (e.g., HTTP)?
- [ ] **A1.1**: Is the protocol open, free, and universally implementable?
- [ ] **A1.2**: If the data is restricted, is the authentication/authorization procedure clearly documented?
- [ ] **A2**: Will the metadata remain accessible even if the data is no longer available?

## Interoperable
- [ ] **I1**: Is the (meta)data represented in a formal, accessible, shared language (e.g., JSON-LD, RDF)?
- [ ] **I2**: Do the vocabularies used follow FAIR principles?
- [ ] **I3**: Does the (meta)data include qualified references to other (meta)data?

## Reusable
- [ ] **R1**: Is the (meta)data richly described with accurate and relevant attributes?
- [ ] **R1.1**: Is the data released with a clear and accessible data usage license?
- [ ] **R1.2**: Is the provenance (history) of the data detailed?
- [ ] **R1.3**: Does the (meta)data meet domain-relevant community standards?
