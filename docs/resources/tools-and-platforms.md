# Tools and Platforms

A curated list of tools to help you implement FAIR principles.

## Repositories

### Generalist
- **Zenodo**: [https://zenodo.org/](https://zenodo.org/) - CERN-hosted, assigns DOIs, supports versioning.
- **Dryad**: [https://datadryad.org/](https://datadryad.org/) - Curated general-purpose repository.
- **Figshare**: [https://figshare.com/](https://figshare.com/) - Commercial repository with free tier.

### Domain Specific
- **GenBank/SRA**: [https://www.ncbi.nlm.nih.gov/genbank/](https://www.ncbi.nlm.nih.gov/genbank/) - Sequences.
- **PRIDE**: [https://www.ebi.ac.uk/pride/](https://www.ebi.ac.uk/pride/) - Proteomics.
- **UniProt**: [https://www.uniprot.org/](https://www.uniprot.org/) - Protein sequence and functional information.

## Metadata Tools

- **CEDAR Workbench**: [https://metadatacenter.org/](https://metadatacenter.org/) - Tools for creating and validating metadata.
- **ISA Tools**: [https://isa-tools.org/](https://isa-tools.org/) - Framework for managing metadata in life sciences.

## Validation Tools

- **FAIRshake**: [https://fairshake.cloud/](https://fairshake.cloud/) - Tool for assessing the FAIRness of digital objects.
- **F-UJI**: [https://www.f-uji.net/](https://www.f-uji.net/) - Automated FAIR data assessment tool.

## Data Management Planning

- **DMPTool**: [https://dmptool.org/](https://dmptool.org/) - Create data management plans that meet funder requirements.
- **DSW (Data Stewardship Wizard)**: [https://ds-wizard.org/](https://ds-wizard.org/) - Smart questionnaires for DMPs.
