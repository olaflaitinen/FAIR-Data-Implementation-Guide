# Getting Started with FAIR Data

Welcome! This guide will help you start your journey towards making your data Findable, Accessible, Interoperable, and Reusable.

## Step 1: Understand the Basics
Read the [Introduction to FAIR Principles](../principles/README.md) (or the individual principle guides) to understand the core concepts.

## Step 2: Assess Your Current State
Use the [FAIR Assessment Checklist](../../checklists/fair-assessment-checklist.md) to evaluate a recent dataset. Don't worry if you score low initially—this is a process!

## Step 3: Create a Plan
For your next project, draft a Data Management Plan (DMP) using our [template](../../templates/data-management/dmp-template.md). This forces you to think about file formats, metadata, and storage *before* you start collecting data.

## Step 4: Adopt a Standard
Identify the metadata standard used in your field.
- **Genomics**: MINSEQE
- **Proteomics**: MIAPE
- **General**: Dublin Core, Schema.org

## Step 5: Use the Tools
Explore the `templates/` directory for ready-to-use metadata files. Try running the `validate-metadata.py` script on your first attempt.

## Step 6: Publish
When your dataset is ready, upload it to a repository like Zenodo, Dryad, or a domain-specific archive. Ensure you get a DOI.

## Need Help?
Check the [Glossary](../resources/glossary.md) for terms you don't understand, or look at the [Case Studies](../case-studies/) for inspiration.
